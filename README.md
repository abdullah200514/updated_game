# 🐦 Flappy Bird with Friend

A personalised Flappy Bird-style browser game built using HTML, CSS and JavaScript. The game features a custom image as the bird character, with obstacles to avoid and a score to beat.

## 🎮 Features

- **Custom bird character:** Uses a personal image as the playable character.
- **Circular image clipping:** Displays the character image inside a circular shape.
- **Flappy Bird gameplay:** Control the bird's movement using keyboard or mouse input.
- **Randomly generated pipes:** Navigate through obstacles positioned at varying heights.
- **Score tracking:** Earn points by passing through pipes.
- **Collision detection:** The game ends when the bird hits a pipe, the ceiling or the ground.
- **Particle effects:** Small visual effects appear when scoring points.
- **Increasing difficulty:** Pipe speed gradually increases during gameplay.
- **Restart functionality:** Restart the game after a Game Over.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Canvas API

## 🚀 How to Run

1. Download or clone this repository.
2. Ensure `index.html` and the required image file are in the same directory.
3. Open `index.html` in a web browser.
4. Click or press Space to start playing.

## 🕹️ Controls

| Action | Control |
|---|---|
| Start the game | Click or press Space |
| Flap | Click or press Space |
| Restart | Click the Restart button |
